# 🏰 Himitsu (秘密)

> **"Welcome Home! Mission Start: 2021.01.01"**

Aokiba & 晓倩 的二人两猫生活记录仪。这是一个充满动漫风格与奇妙冒险感的家庭个人网站，记录了名为“生活”的 RPG 游戏中，公会成员们的羁绊与升级历程。

![Hero Preview](src/assets/hero-anime.jpeg)

## 🌟 特性 | Features

*   **🌸 动漫风视觉体验**：新海诚风格的 Hero 背景，高饱和度的 Anime Pop 配色。
*   **🐱 沉浸式迎接动画**：打开网站，甜心 (Mage) 和 蛋糕 (Warrior) 会从屏幕两侧跑来迎接你回家。
*   **⏳ 羁绊计时器**：实时计算“公会成立”天数（在一起的纪念日）。
*   **📅 智能家庭日历**：
    *   集成农历/公历生日自动转换（再也不会忘记晓倩的农历生日了！）。
    *   重要纪念日倒计时提醒。
*   **📱 移动端适配**：无论是在电脑还是手机上，都能完美访问秘密基地。

## 🛠️ 技术栈 | Tech Stack

*   **Core**: React 19, TypeScript
*   **Build**: Vite
*   **Styling**: Tailwind CSS v4 (Oklch Colors)
*   **UI Components**: shadcn/ui, Lucide React
*   **Animation**: Framer Motion
*   **Date/Time**: date-fns, lunar-javascript

## 🚀 快速开始 | Quick Start

### 1. 克隆项目
```bash
git clone https://github.com/your-username/himitsu.git
cd himitsu
```

### 2. 安装依赖
本项目使用 `pnpm` 进行包管理。
```bash
pnpm install
```

### 3. 启动开发服务器
```bash
pnpm dev
```
访问 http://localhost:5173 即可进入秘密基地。

### 4. 构建生产版本
```bash
pnpm build
```
